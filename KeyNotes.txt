2. Python and its exceptions:
    2.1. Common Built-in Exceptions (The Most Frequent)These are standard errors that occur during regular program execution:
    ValueError: A function receives an argument with the right type but an inappropriate value (e.g., int("apple")).
    TypeError: An operation or function is applied to an object of inappropriate type (e.g., len(5)).
    IndexError: A sequence subscript (like a list index) is out of range (e.g., accessing my_list[10] on a 3-item list).
    KeyError: A dictionary key is not found (e.g., my_dict["missing_key"]).
    AttributeError: An attribute reference or assignment fails (e.g., trying to use a string method on an integer).
    2.2. Operational & Environment ExceptionsThese exceptions happen due to external factors or system limitations:
    FileNotFoundError: A file or directory is requested but does not exist.
    PermissionError: Trying to run an operation without the necessary system permissions.
    ZeroDivisionError: Second argument of a division or modulo operation is zero (e.g., 1 / 0).
    ModuleNotFoundError: An import statement fails to find the specified module.
    TimeoutError: A system function or network request times out.
    2.3. Structural & Critical ExceptionsThese usually point to fatal bugs or direct system interventions:
    SyntaxError: The parser encounters a syntax error (e.g., missing a colon : or closing parenthesis).
    IndentationError: Incorrect indentation, which is vital in Python (e.g., mixing tabs and spaces).
    NameError: A local or global name is not found (e.g., using a variable x before defining it).
    KeyboardInterrupt: The user hits the interrupt key (usually Ctrl+C).SystemExit: Raised by the sys.exit() function to close the program

1. Network & Timeout Exceptions:
    OperationalError: The most common connection exception. It triggers when the database server is down, the IP/host is incorrect, or a firewall blocks the port.
    TimeoutError / ConnectionRefusedError: Built-in Python errors raised if the server takes too long to respond or actively rejects the connection handshake.
2. Authentication & Authorization Exceptions
    OperationalError (with Auth context): Most drivers (like psycopg2) raise this with an internal message like "password authentication failed" if your password or token is wrong.
    ProgrammingError: Raised if the user specified in the connection string exists, but does not have permission to access the target database.
    SecurityError (or driver equivalents): Raised when SSL/TLS certificate validation fails during a secure connection attempt.
3. Configuration & Target Exceptions
    OperationalError (Missing DB): Triggered when the host is correct, but the specific database name you provided cannot be found on that server.
    InterfaceError: Raised if the error is linked to the database driver itself rather than the database (e.g., passing invalid parameters inside the connection string wrapper).
